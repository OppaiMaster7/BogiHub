# BogiHub 0.1.2: smoother ZIP, optional update check

**Try the installer first. If it will not open or installation fails, download the ZIP.**

| Download | Use this for |
| :--- | :--- |
| **[BogiHub installer (.exe)](https://github.com/OppaiMaster7/BogiHub/releases/download/v0.1.2/BogiHub-Setup-0.1.2.exe)** | The normal installation, with shortcuts and the ViGEmBus driver. |
| **[BogiHub portable (.zip)](https://github.com/OppaiMaster7/BogiHub/releases/download/v0.1.2/BogiHub-Portable-0.1.2-win-x64.zip)** | When Setup is blocked, for example by Smart App Control (“Unable to execute file in the temporary directory”, Error 4551). |
| **[Official ViGEmBus driver](https://github.com/nefarius/ViGEmBus/releases/download/v1.22.0/ViGEmBus_1.22.0_x64_x86_arm64.exe)** | Required for gamepad mode. Both downloads above already include it. |

## What's new

1. **The driver button installs the driver in the ZIP version.** **Install ViGEmBus driver** now runs the driver
   installer from the ZIP's **drivers** folder instead of sending you to a web page, and checks again when it's done.
2. **Start with Windows follows a ZIP update.** Extract the new ZIP into a new folder, open it once, and Windows
   starts the new copy from then on (before, it kept starting the old one).
3. **Optional update check.** Turn on **Settings** > **Updates** > **Check for new versions** and BogiHub tells you
   when a newer version is out. It's **off until you turn it on**, asks GitHub at most once a day, and sends nothing
   but the question. **Check now** works any time.
4. **The ZIP and Smart App Control.** On a Windows 11 PC with Smart App Control on, the installer was blocked and the
   ZIP worked. The download page says so now.

## Updating

**Installer:** run the new installer. It closes BogiHub for you and keeps your settings and profiles.

**ZIP:** exit BogiHub from its tray menu, extract the new ZIP into a new folder and open the new **BogiHub.exe**.
Settings and profiles stay in `%APPDATA%\BogiHub`.
