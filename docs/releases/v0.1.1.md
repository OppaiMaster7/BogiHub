## Requirements

> [!IMPORTANT]
> **ViGEmBus MUST be installed on this PC for gamepad mode.** Without it, games will not see BogiHub's virtual
> Xbox controller. Install the driver once on each PC. ZIP users must run the included driver installer themselves.

| You need | Details |
| :--- | :--- |
| **Windows 10 or 11, 64 bit** | No separate .NET installation needed. |
| **Steam Controller (2026)** | Tested with the wireless puck. The USB cable and Bluetooth aren't tested yet. |
| **Administrator permission** | Only for the ViGEmBus driver. BogiHub itself runs without it. |

## Method 1: Installer (try this first)

1. Download and open **BogiHub-Setup-0.1.1.exe**.
2. Click **Next** through the setup screens. **Leave “Install the ViGEmBus driver” ticked** if offered.
3. Click **Install**, allow the driver's administrator prompt, and restart if requested.
4. Click **Finish**, turn on the controller, and open your game.

**If Setup is blocked or will not open, try Method 2 below.**

## Method 2: ZIP (if the installer fails)

1. Download **BogiHub-Portable-0.1.1-win-x64.zip** above. GitHub's automatic **Source code (zip)** is not the app.
2. Right-click the downloaded ZIP, choose **Extract All…**, then **Extract**. Do not run it from inside the ZIP preview.
3. **Install ViGEmBus:** in the extracted folder, open **drivers** and run **ViGEmBus_1.22.0_x64_x86_arm64.exe**. Finish setup, allow the administrator prompt, and restart if asked. Skip this step only if the driver is already installed.
4. Return to the extracted folder and open **BogiHub.exe**. Keep all extracted files together.
5. In BogiHub's **Settings**, check that **Virtual Xbox controller** says **Installed**. Turn on your controller and play.

The ZIP includes **START-HERE.txt** with these instructions. It skips BogiHub's installer, but Windows may still
block the unsigned app or a library. It is not a guaranteed fix for Smart App Control.

## What's changed

1. Added a portable ZIP with the official, verified ViGEmBus installer and plain setup instructions.
2. Put the installer, ZIP and driver download links at the top of the GitHub page.
3. Cleaner text in the installer artwork, and optional signing with your own certificate.

This is still an early preview. See the [compatibility notes](https://github.com/OppaiMaster7/BogiHub/blob/main/docs/compatibility.md)
for testing coverage. Settings and profiles remain in `%APPDATA%\BogiHub` with either download.

Download [SHA256SUMS.txt](https://github.com/OppaiMaster7/BogiHub/releases/download/v0.1.1/SHA256SUMS.txt)
